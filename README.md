# 화천 Parking Mate

KNU RE:RISE 7팀의 **축제 주차 분산 안내·QR 예약 검증용 웹 서비스**입니다.

- 체험 페이지: https://psb6420.github.io/Hwacheon_Parking_Mate/
- 독립 저장소: https://github.com/psb6420/Hwacheon_Parking_Mate
- 참고 프로젝트: https://github.com/psb6420/KANGWON_Parking_Mate

기존 프로젝트의 지도 중심 주차 탐색, 여유율·거리 기반 추천, 서버 연동 구조를 참고했습니다. 기존 Git 이력과 소스·환경변수를 복제하지 않고 화천 프로젝트에 맞춰 새로 구현했습니다. 외부 지도 키 없이 실행할 수 있도록 Leaflet/OpenStreetMap을 사용합니다.

## 구현 기능

- 주차장 지도/목록, 검색, 도보·셔틀 우선 추천, 보행 편의 필터
- 1대당 1면 QR 예약, 30분 만료, 취소, 내 예약 복구
- 운영자 일반 차량 수·운영 중지 변경, QR 코드/수동 코드 입차·출차
- 카메라 스캔(BarcodeDetector 지원 브라우저), 미지원 시 수동 코드
- 만차·운영 중지·15분 이상 오래된 상태의 신규 예약 차단
- 이미 입차한 QR 재사용 차단, 수용량 초과 변경 방지
- 로컬 체험 / 공유 API 어댑터, SQLite 트랜잭션 기반 동시 예약 처리
- 모바일 화면, GitHub Actions 테스트·자동 Pages 배포

**모든 주차 구역·위치·수용 대수·셔틀 정보·이동시간은 예시입니다. 실제 예약/길찾기로 사용하지 마세요.** 가까운 도보 추천은 보행 거리 예시 기반이며 도로 경로 계산·교통 API·GPS 지오펜스·문자 발송·IoT는 아직 연결되지 않았습니다. 보행 편의 필터는 장애인 전용면의 예약을 보장하지 않습니다.

## 실행

Node.js 24 이상:

```sh
npm ci
npm run dev
```

http://127.0.0.1:5173 에서 실행합니다. API 설정이 없으면 같은 브라우저의 localStorage에 저장합니다. 다른 기기에서는 같은 QR을 확인할 수 없고, 브라우저 저장소를 지우면 시연 예약도 사라집니다. 운영자 화면에서 예시 상태를 초기화할 수 있습니다. Web Locks 지원 브라우저에서는 탭 간 예약 변경을 직렬화하며, 미지원 브라우저 체험판은 단일 탭으로 사용하세요.

## 공유 서버 실행

1. `.env.example`을 `.env`로 복사합니다.
2. `ADMIN_KEY`에 32자 이상의 무작위 키를 설정합니다.
3. `VITE_API_BASE_URL=http://127.0.0.1:8787`을 설정합니다.
4. 별도 터미널에서 `npm run server`, `npm run dev`를 실행합니다.
5. 운영자 화면에 ADMIN_KEY를 입력합니다. 입력한 키는 탭 메모리에만 보관합니다.

API는 기본적으로 로컬 주소에만 바인딩합니다. 외부 서버 운영 시 HTTPS, 영속 디스크의 `DB_PATH`, 정확한 `ALLOWED_ORIGINS`, 보호된 운영자 인증과 네트워크 제한을 구성하세요. API의 샘플 데이터도 아직 실제 데이터가 아닙니다.

GitHub Pages 자체에서는 Node/SQLite 서버를 실행할 수 없습니다. 외부 API를 준비한 뒤 GitHub Actions 변수 `VITE_API_BASE_URL`에 공개 API 주소만 넣고 다시 배포합니다. ADMIN_KEY는 빌드 변수에 넣지 않습니다. 공유 서버가 끊기면 오류를 표시하며 로컬 예약으로 자동 전환하지 않습니다.

## GitHub Pages

Settings → Pages → Source를 **GitHub Actions**로 지정합니다. main push마다 `.github/workflows/pages.yml`이 테스트, 빌드, 배포합니다. `base: './'`로 저장소 하위 경로를 지원하고 hash 기반 화면 전환을 사용합니다.

```sh
npm test
npm run build
npm run preview
```

## 데이터·보안 경계

개인 이름·전화번호·차량번호를 수집하지 않습니다. 예약 토큰은 입차용 비밀 코드이며 타인에게 공유하지 않습니다. 서버는 공개 목록에서 토큰과 기기 식별자를 제외하고 운영자 변경에 인증을 요구합니다. IP 단위 요청 제한은 기본 보호이며, 실서비스에는 예약 남용 방지와 담당자 계정별 권한 관리가 추가로 필요합니다. 서버는 종료된 예약을 7일 후 정리하며 최신 운영 기록 100개를 유지합니다. 데이터 파일은 저장소에 포함하지 않습니다.

현장 센서 값은 일반 차량 수와 QR 차량을 중복 집계하지 않도록 정의해야 합니다. 현재 일반 차량 수는 QR 입차 차량을 제외한 값입니다. 확인된 예약은 운영 중지 이후에도 운영자가 현장 판단으로 입차 처리할 수 있으며, 신규 예약은 차단합니다.
