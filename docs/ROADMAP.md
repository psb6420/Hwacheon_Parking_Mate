# 구현 현황과 현장 연동 계획

## 완료
GPS 화천군 진입 판정·위치/주차 여유 기반 자동 배정·도로 경로/음성/이탈 재탐색, 지도·분산 현황·셔틀/도보 정보 표시, 차량 1대 QR 예약, 취소/만료, 입출차, 중복처리 방지, 운영자 수동 상태 변경, stale 상태 차단, 로컬 체험, SQLite 공유 API, Pages 배포 자동화.

## 담당 주무관 인터뷰 후 확정
1. 실제 주차장 좌표·입구·일반/예약/교통약자 구역 수용 대수·운영 주체.
2. 혼잡 시간대, 차량 진입 경로, 만차 전달 방식, 잔여면 데이터 제공 방식.
3. 센서 값/수동 값 우선순위와 갱신 주기, 운영 종료·임시 폐쇄 처리.
4. 셔틀 정류장·운행시간·배차·실제 도보 경로.
5. QR 지정 구역, 예약 유지 시간, 노쇼, 일반 차량과의 배분, 현장 운영자 권한.
6. 시범 구역과 승인 절차, 공식 웹사이트 안내 연결 여부.

## 후속 구현 순서
1. 확인된 자료와 출처/확인일을 함께 등록. 현재 샘플 카탈로그를 공식 데이터로 오인하지 않도록 유지.
2. 운영시간 자동 예약 차단, 전용 구역별 수용량과 단체차량 정책 반영.
3. 담당자별 로그인·권한, 서버 예약 남용 방지, 토큰 재발급/회수, 보관 정책·운영 로그.
4. 실운영 경로 API·교통 통제와 공식 셔틀/도보 경로 연동. 현재 OSRM 데모 경로를 운영 승인된 서비스로 전환. 비밀키는 서버에 저장.
5. 데이터가 확보될 때 실시간 만차 전환·다른 구역 추천 알림 연결.
6. 최신 공식 경계 검증·위치 위조 대책 및 GPS 미지원자의 현장 대체 신청 협의.

## 검증 시나리오
- 마지막 1면 동시 예약에서 1건만 성공.
- 예약 취소와 30분 만료 시 정확히 1면 반환.
- 입차는 hold를 점유로 전환해 여유면이 변하지 않음. 출차 시 1면 반환.
- 만차/운영 중지/15분 초과 정보에서는 예약 차단.
- 운영자 일반 차량 수 변경으로 기존 예약 수용량을 침범하지 않음.
- QR 재스캔 거부, 운영자 인증 누락 거부, 허용되지 않은 Origin 거부.
- 모바일 검색·예약·QR·입출차·새로고침, Pages 하위 경로 자산 로딩.

## 실제 행사 운영 전 남은 조건
데이터 제공·시범 운영 승인, 전용 예약면 확보, HTTPS API 배포와 백업/복구, 현장 운영자 교육, 장애 시 수동 안내, 정확한 개인정보·로그 정책. 현재 공개 Pages는 발표·사용성 검증용입니다.
